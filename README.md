# TCP Port Forwarder (Проброс портов)

Утилита проброса TCP-портов для Windows с выводом статуса на экран и записью всех событий (подключение, отключение, ошибки) в журнал событий Windows (**EventViewer -> Application**).

---

## 🚀 Быстрый запуск

### 1. Запуск с параметрами по умолчанию
Слушает на всех интерфейсах (`0.0.0.0` / IPv6 Dual-Stack) на порту `2022` и пробрасывает трафик на `192.168.1.150:22`:

```powershell
.\publish\PortForwarder.exe
```
или через .NET:
```powershell
dotnet run
```

---

### 2. Запуск с произвольными параметрами (включая множественные правила)

Формат правил:
`*([listen_ip][:])!([listen_port][:])!([target_ip][:])!([target_port])`

- `listen_ip` (опционально, `*`): интерфейс прослушивания (по умолчанию `0.0.0.0` — все сетевые карты).
- `listen_port` (обязательно, `!`): локальный порт прослушивания.
- `target_ip` (обязательно, `!`): целевой IP-адрес или хост.
- `target_port` (обязательно, `!`): целевой порт.

```powershell
# Классический формат (слушает на всех интерфейсах 0.0.0.0)
.\publish\PortForwarder.exe 2022:192.168.1.150:22

# Явное указание интерфейса (только локальный loopback 127.0.0.1)
.\publish\PortForwarder.exe 127.0.0.1:2022:192.168.1.150:22

# Привязка к конкретному сетевому адаптеру (например, LAN 192.168.1.24)
.\publish\PortForwarder.exe 192.168.1.24:8088:192.168.1.150:8080

# Несколько правил одновременно с разными интерфейсами
.\publish\PortForwarder.exe 0.0.0.0:2022:192.168.1.150:22 127.0.0.1:8080:192.168.1.150:80 192.168.1.24:3389:192.168.1.200:3389

# С настройкой таймаута неактивных соединений (Keep-Alive Idle Timeout, по умолчанию 120 сек)
.\publish\PortForwarder.exe --idle-timeout 60 2022:192.168.1.150:22
```

> **Важно:** Защита от петель (Self-Loop) предотвращает запуск правил вида `8080:127.0.0.1:8080` или `0.0.0.0:8080:127.0.0.1:8080`, когда порт прослушивания совпадает с целевым на этом же компьютере. При этом проброс с отдельного интерфейса на локалхост (например: `192.168.1.24:8080:127.0.0.1:8080`) разрешен, так как сокеты разделены.

Или через `dotnet run`:
```powershell
dotnet run -- 192.168.1.24:8088:192.168.1.150:8080
```

## 🖥 Отображение статуса на экране

Во время работы приложение выводит подробные цветные логи и статус:
- **`[LISTENER]`** — Старт прослушивания на указанных портах.
- **`[CONNECT]`** — Подключение клиента с указанием IP клиента, целевого адреса, количества активных и общего числа проброшенных соединений.
- **`[DISCONNECT]`** — Отключение клиента с временем сессии, переданным трафиком (отправлено/получено) и текущим числом активных подключений.
- **`[ERROR]`** — Ошибки при недоступности целевого узла или сбросе соединения.
- **Клавиша `S`** — Нажмите `S` в окне консоли в любой момент для вывода сводной таблицы текущего статуса всех правил.
- **Клавиша `I`** — Нажмите `I` для просмотра статистики подключений по IP-адресам (Всего подключений, объём трафика к каждому IP, ТОП-5 портов, число уникальных портов, автоматический детект порт-скана 1-65535, а также интерактивный ввод номера строки для детализации с объёмом трафика по каждому из портов).

Пример вывода:
```text
================================================================================
                     TCP PORT FORWARDER (ПРОБРОС ПОРТОВ)                       
================================================================================
Режим прослушивания: Все сетевые интерфейсы (0.0.0.0 / Dual-Stack IPv4+IPv6)
Логирование: Консоль + Windows EventViewer -> Application
--------------------------------------------------------------------------------
Активные правила проброса:
  * Порт 2022  ==>  192.168.1.150:22
--------------------------------------------------------------------------------
Нажмите Ctrl+C для остановки. Нажмите 'S' для вывода текущей статистики.
================================================================================

[2026-10-07 17:36:56.293] [LISTENER  ] Служба запущена: порт 2022 на всех интерфейсах -> 192.168.1.150:22
[2026-10-07 17:36:58.264] [CONNECT   ] [#1] Подключен клиент: 10.0.0.5:49877 -> 192.168.1.150:22 (Слушаем :2022) | Активных: 1 | Всего: 1
[2026-10-07 17:36:58.296] [DISCONNECT] [#1] Отключен клиент: 10.0.0.5:49877 (Правило :2022 -> 192.168.1.150:22) | Длительность: 12.4с | Трафик: ↑ 4.2 KB, ↓ 8.9 KB | Активных: 0
```

## 📋 Логирование в Windows EventViewer (Журнал приложений)

Все события автоматически записываются в:
> **Просмотр событий (Event Viewer) -> Журналы Windows (Windows Logs) -> Приложение (Application)**

### Коды событий (Event ID):
| Event ID | Тип | Описание |
|---|---|---|
| **1001** | Information | Запуск службы проброса для правила |
| **1002** | Information | Подключение нового клиента |
| **1003** | Information | Отключение клиента (с длительностью и объёмом данных) |
| **1004** | Information | Корректная остановка службы |
| **1005** | Information | Итоговая статистика работы службы перед закрытием (как по клавише S) |
| **2001** | Error / Warning | Ошибка сетевого листенера |
| **2002** | Error | Ошибка соединения с целевым хостом |
| **3001** | Error | Критическая ошибка старта |

### Просмотр через PowerShell:
```powershell
Get-EventLog -LogName Application -Newest 20 | Where-Object { $_.Message -like "*PortForwarder*" }
```
